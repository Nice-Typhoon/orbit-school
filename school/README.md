# Орбита — образовательная платформа

Школьные материалы, интерактивные курсы, тренажёр и защищённый редактор преподавателя.

## Вход и права

Вход работает через ChatGPT, предоставляемый Sites. Сайт не хранит собственных паролей.

- Ученик читает опубликованные материалы и проходит уроки и тренировки.
- Преподаватель редактирует общую библиотеку, видит черновики и загружает PDF.
- Владелец добавляет и отключает преподавателей в /#/admin/teachers.

Изначально права есть только у владельца. Его email задаётся серверной переменной OWNER_EMAIL в окружении Sites. В клиентском коде этого значения нет. Отсутствующая переменная никому не выдаёт доступ.

Новые преподаватели добавляются по email аккаунта ChatGPT. При первом входе разрешённый email привязывается к идентификатору пользователя внутри сайта. Отзыв доступа применяется при каждом новом запросе, даже если вкладка редактора ещё открыта. Просто войти в ChatGPT недостаточно для получения роли преподавателя.

Все /api/admin/* проверяют роль на сервере. Управление преподавателями дополнительно требует владельца. Запросы изменений проверяют Origin. API не доверяет ролям из localStorage или JavaScript. Публичный API не выдаёт черновики. Проверка версии библиотеки предотвращает перезапись изменений другого преподавателя.

Доступ ко всему приватному сайту и роль преподавателя — разные уровни. Преподавателю также нужен доступ к самому сайту. Аудитория сайта этим обновлением не меняется.

## Хранение и перенос

Общая библиотека и преподаватели хранятся в D1, PDF — в R2. Sites создаёт ресурсы и применяет миграции при публикации. Прогресс и история тренировок остаются локальными на устройстве ученика.

В браузере сохраняется копия библиотеки прежней локальной версии. Владелец может перенести её и старые PDF через Редактор → Настройки. Перенос заменяет общую библиотеку, поэтому сначала экспортируйте текущую копию. Если старое вложение отсутствует, перенос останавливается с сообщением. Произвольная загрузка локальной копии учеником не изменяет серверную библиотеку.

PDF.js показывает PDF без стандартной панели скачивания. Полностью запретить сохранение документа, открытого в браузере, невозможно. PowerPoint нужно экспортировать в PDF; максимальный размер — 20 МБ. Удаление ссылки на вложение закрывает его публичный просмотр после сохранения курса; физическая очистка неиспользуемых объектов требует отдельной политики хранения.

## Локальная разработка

Нужен Node.js 22.13+ и npm. Установка: npm ci.

В игнорируемом файле .dev.vars задайте OWNER_EMAIL=seedy@sites.test. Это тестовый аккаунт локального входа, работающий только на loopback. В опубликованной версии используется реальный вход ChatGPT. Для проверки ученика укажите другой локальный OWNER_EMAIL и перезапустите сервер.

Сначала npm run build, затем примените локальную миграцию:

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_kind_eternity.sql
npm run dev
```

Сервер показывает локальный адрес, обычно http://127.0.0.1:5173. Прежняя команда node server.mjs также запускает новый сервер. Локальная база отдельная от опубликованной.

Проверки:

```sh
node --test tests/access.test.mjs tests/data.test.mjs
node node_modules/typescript/bin/tsc --noEmit
```

Для HTTP-проверок задайте API_TEST_BASE_URL=http://127.0.0.1:5173 и запустите node --test tests/http-auth.test.mjs. API_TEST_STUDENT=1 проверяет вошедший аккаунт без прав; локальный OWNER_EMAIL должен отличаться от seedy@sites.test.

## Исходники

- public/app.js, styles.css, data.js — интерфейс и стартовая демонстрационная библиотека.
- public/api-client.js — сессия, загрузка и сохранение через сервер.
- public/storage.js — локальный прогресс и старые вложения для переноса.
- app/route.ts, app/shell.html — HTML; app/chatgpt-auth.ts — вход Sites.
- app/api/[...path]/route.ts, lib/api.ts — серверные маршруты.
- lib/access.mjs — роли и Origin; lib/library-validation.mjs — валидация библиотеки.
- db/schema.ts, drizzle/ — схема и миграции.

Содержание — демонстрационные уроки, не полная школьная программа и не официальный комплект ЕГЭ. PDF.js включён локально с лицензией Apache 2.0 в public/vendor/PDFJS-LICENSE.txt.
